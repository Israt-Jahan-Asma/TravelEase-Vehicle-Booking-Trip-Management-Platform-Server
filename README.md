
# Project Title

🚀 TravelEase Server - Backend API for the TravelEase travel booking platform.


## Overview
The TravelEase Server is built using Node.js, Express, and MongoDB to handle all backend operations such as user management, package bookings, CRUD operations, and secure API routing.
## Features
- RESTful API endpoints
- Secure environment variable handling using dotenv
- CORS enabled
- MongoDB database connection
- CRUD operations for travel packages, users, bookings
- Error-handled Express routes
## Technologies Used
- Node.js
- Express.js (v5)
- MongoDB Driver
- dotenv
- CORS
## Installation & Setup

1️⃣ Clone the repository <br>
git clone https://github.com/yourusername/travelease-server.git
cd travelease-server

2️⃣ Install dependencies <br>
(npm install)

3️⃣ Add your .env file <br>
DB_USER=your_user<br>
DB_PASS=your_pass<br>
DB_NAME=your_db<br>
PORT=5000

4️⃣ Start the server <br>
npm start

🔗 API Base URL <br>

Example:

https://travelease-server.vercel.app
